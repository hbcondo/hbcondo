SOCIAL MEDIA

MySpace

Engineering work across MySpace and MySpaceTV that helped internationalize the platform, connect members, protect conversations, and keep video experiences uninterrupted.

01
UK / IE Interstitial

Created a post-login experience that directed millions of United Kingdom and Ireland users to their localized MySpace sites. The work included ColdFusion login-flow business logic, a lightweight HTML and JavaScript page, and SQL tracking. Within days, a majority of affected users had switched their preferred culture.

02
Resource Manager

Developed comparison functionality for an internal application used by developers and product managers to manage localization RESX files. The algorithms identified missing and extra keys across cultures, with a C# 2.0 and ASP.NET 2.0 interface that included JavaScript context menus.

03
Address Book Importer

Built the module that let members invite contacts from Yahoo!, Hotmail, Gmail, and AOL. It authenticated with each provider, parsed contacts with HTML Agility Pack, checked MySpace's user database, and separated existing members from contacts who could be invited.

04
Country and Culture Mapping

Created configurable culture-to-country mappings using C# 2.0 and XML deserialization. A provider-based API exposed those settings to other teams building applications for international versions of MySpace.

05
Japan Groups API

Developed an API for Japanese MySpace Groups engineers, including SQL Server 2005 stored procedures, data-access objects, provider classes, domain objects, and UML class diagrams documenting its use.
