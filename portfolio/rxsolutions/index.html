HEALTHCARE

RxSolutions

Six years of e-commerce and intranet engineering for a pharmacy and medical management platform serving prescription and over-the-counter medication customers.

01
Formulary

Developed an interface that displayed formulary and non-formulary prescription drugs based on a member's health plan, including alternatives and search by brand, generic name, or therapeutic class.

02
Pharmacy Locator

Built location search by city, state, or ZIP code, with pharmacy contact information and MapQuest integration for maps and driving directions.

03
Prescription Refills

Developed one of the site's most-used features, retrieving prescription data from an internal VAX system through .NET Remoting, calculating refill eligibility, and integrating eligible prescriptions with the shopping cart.

04
Prescription Order History

Created annual prescription-history views backed by an AS/400 system, with .NET Remoting access, Patient Education Letter links, and printer-friendly output.

05
Web Analytics

Installed WebTrends Reporting Center to replace an outdated reporting system and provide nightly website statistics through a browser-accessible interface.

06
Over-the-Counter Sales

Implemented data-driven OTC sale pricing so business users could schedule prices without additional development. The site reached record OTC sales during the first month after launch.

07
OTC Inventory Status

Added product-level out-of-stock messaging backed by RxExpress inventory extracts, preventing customers from discovering availability issues only after adding products to their cart.

08
Reports Web Interface

Created a Crystal Enterprise interface for browsing and drilling into reports, then modularized its shared components for both the authenticated client portal and company intranet.

09
Communications Modernization

Helped replace a Java COM integration with a flexible .NET Remoting API and updated more than 60 web pages to use the new RxExpress communication layer.

10
Consumer Homepage

Built a personalized post-login homepage showing recent purchases, health-plan messages, and prescription shortcuts, with persistent color-theme and font-size accessibility settings.

11
Prescription Drug Pricing

Co-developed a Medicare-era drug pricing application that let consumers compare medication prices by dosage and location across neighboring pharmacies.

12
Prior Authorization Guidelines

Published searchable Medicaid prior-authorization policies online so physicians and members could identify covered medications and health-plan requirements without calling support.

13
RxNews Newsletter

Developed a CMS-backed newsletter for healthcare professionals covering drug safety, recalls, labeling changes, pipeline medications, and clinical studies, with automatic email notifications for new content.

14
PBI Newsletter Redesign

Redesigned Pharmacy Benefit Insider and upgraded its newsletter generator from ASP 3.0 to ASP.NET, VB.NET, ADO.NET, and SQL Server 2000.

15
Search Engine

Implemented site search using Microsoft Indexing Service and SQL Server, and standardized title, keyword, and description metadata across searchable pages.

16
AS/400 Integration

Enhanced a Temporary ID application to call a web service that executed AS/400 stored procedures through the IBM iSeries Access ODBC driver and returned XML responses.

17
PrescriptionSolutions.com

Developed the consumer portal for the Medicare Part D website, including new-prescription ordering and refill requests built with ASP/JScript, SQL stored procedures, and web services.
