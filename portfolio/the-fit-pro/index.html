The Fit Pro

An interactive health and fitness search platform connecting members with fitness professionals, facilities, content, and commerce.

01
Member Communication

Created tools for private email, profile comments, and member questions, with professional approval and response workflows. The ASP.NET and C# features used YUI and AJAX for form submissions.

02
E-Newsletter

Built a database-driven ASP.NET newsletter using master pages and user controls, producing XHTML-compliant output for Constant Contact email campaigns to clients and members.

03
Widget as a Service

Developed a portable JavaScript search widget that partners could embed with a few lines of code while TheFitPro.com retained centralized update control. Gigya distribution added sharing and installation analytics.

04
Picture Carousel

Built an animated, SEO-friendly YUI carousel for featured professionals and facilities, backed by a C# and ASP.NET content-management interface storing selections in SQL Server 2005.

05
SEO-Friendly URLs

Implemented unique extensionless member-profile URLs through a custom C# HTTP module, including permanent 301 redirects to improve usability and search-engine indexing.

06
XML Sitemaps

Created a dynamic .NET application that queried thousands of active member profiles and generated Sitemap.org XML metadata for submission to Google, Yahoo, and Microsoft.

07
Fitness Store

Integrated an AbleCommerce shopping cart with the existing website, including IIS configuration, a new SQL Server 2005 database, and access to commerce features through the platform's .NET API.
