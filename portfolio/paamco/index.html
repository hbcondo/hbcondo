FINANCE

PAAMCO

Risk-data engineering and platform modernization for a leading independent fund-of-hedge-funds investment firm managing more than $11 billion in assets.

01
Web Services

Oversaw WCF SOAP services that exposed Security Master data to applications outside the Risk group, supporting manager-security analytics and regulatory audit transparency.

02
Municipal Bond Data Loader

Created a process that parsed complex Bloomberg municipal-bond schedules and persisted them to the Risk database using a third-party schema, enabling analysis that had not previously been possible.

03
Flagsheet Report

Managed development of a faster Flagsheet report and web-based limit editor, moving calculations into SQL procedures and functions and adding configurable cell highlighting to provide a consistent alternative to Excel workflows.

04
Agile Scrum Delivery

Introduced daily Scrum coordination and monthly planning to the Risk Data team, along with a TFS team project for tracking initiatives, tasks, bugs, and code changes.

05
Risk Web Portal

Created a centralized portal for portfolio managers to access Risk Data applications and reports through memorable links, using a shared codebase to improve reuse and maintenance.

06
Reporting Services

Migrated Risk Data reports from SQL Server 2000 to SQL Server 2005 Reporting Services, enabling third-party charts, source-controlled report definitions, and one-click deployments.

07
Source Control Implementation

Partnered with IT on a company-wide Team Foundation Server rollout and established the Risk Data repository for safely versioning applications and reports while managing projects, bugs, and assignments.

08
Development Environment

Configured a dedicated Risk development environment for safely testing SQL, reports, and web applications before release, replacing disruptive testing against the live production database.
